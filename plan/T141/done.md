Do: replace T76's interactive y/N restart prompt with an automatic, no-prompt flow. For each host in a `rtok agents install|uninstall` request, only for a `Kind::Desktop` variant: if the app is running (checked without a launch side effect) and the write would actually change something for that host (dry-run via `agents::would_change`, reusing `apply_all` exactly as `run` does) — quit it before writing, write, then reopen it after.
